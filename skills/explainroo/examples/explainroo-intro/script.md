# explainroo

> Launch video. Every claim here is true of the kit as built.

## hook
A coding agent made this video with explainroo. It didn't use [#nomodel] a video model, [#nokeys] an API key [#noedit] or a video editor. [#code] Everything you see is drawn with JavaScript.

## files
explainroo is a free, open source kit for coding agents. [#writes] The agent writes two files. [#script] The first one is the script for the voice. [#scenes] The second one is a bit of JavaScript that draws the pictures.

## voice
A voice model called Kokoro reads the script. [#local] It runs on your own computer. [#whisper] Then Whisper listens to the recording and writes down the time of each word.

## sync
This way a picture can appear at the moment the voice mentions it. [#code] The agent writes one line of code, [#say] and when the voice says database, the database appears.

## draw
Chrome draws each frame in the background. [#looks] There are five looks to pick from, [#sound] and explainroo also makes the music and the sound effects.

## eyes
The agent can't watch the video, [#give] so explainroo turns it into things the agent can read. [#stills] It makes still pictures of each scene [#sheets] and contact sheets that show a scene over time. [#check] A check also finds text that is cut off, bad timing and words the voice got wrong.

## render {min=5.5}
One command turns all of it into an MP4 file.

## outro {hold=2}
explainroo is free and open source. [#try] The code and these example videos are on GitHub.
