# DSH 场景绘制

完整绘图 API 见安装技能时从原版依赖生成的 [上游指南](upstream-guide.md)。不要修改引擎。

项目的 `scenes.js` 默认导出场景对象，方法键与讲稿场景 ID 相同。可使用中文名称。每帧调用绘图函数，以 `at`、`out` 控制时间。

```js
export default {
  开场(s) {
    s.text("欢迎", { id: "标题", x: 960, y: 320, at: "#出现" });
    s.box("步骤一", { id: "步骤", x: 960, y: 600, w: 500, h: 240 });
  },
};
```

`text`、`box`、`circle`、`icon`、`image` 可在工作台中调整基础属性。稳定的对象 `id` 有助于保留手动修改。复杂 `s.draw` 继续通过代码维护。

使用项目内的静态相对模块导入；不要动态拼接场景和触发点名称。修改后运行无声验证，再查看工作台预览。
