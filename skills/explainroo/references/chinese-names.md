# 中文命名与引用验证

DSH 插件支持中文、字母、数字、下划线和短横线，名称最多 80 个字符，使用 NFC 规范，不含空格、路径符号或 Windows 保留名称。场景名在项目内唯一，触发点名在本场内唯一。名称本身就是引用键，没有独立显示名或翻译字典。

```markdown
## 开场介绍
[#认识账户] 要理解 Solana，先理解账户。
[#展开内容] 余额、代币、程序状态，全都放在账户里。
```

```js
export default {
  '开场介绍'(s) {
    s.text('Solana 账户', { id: '标题', at: '#认识账户' });
    s.box('余额与状态', { id: '账户', at: '#展开内容' });
  },
};
```

## 修改与验证

- 使用 `explainroo_rename({id,revision,sceneId,kind:'scene',to:'开场介绍'})` 修改场景名。
- 使用 `explainroo_rename({id,revision,sceneId,kind:'marker',from:'account',to:'认识账户'})` 修改触发点。先取最新 revision，每次修改后使用返回的新 revision。
- 改名更新讲稿、AST 定位到的画面引用、封面和手动 at/out；有效配音保持音频字节，更新名称、标记与缓存 hash。撤销同时恢复来源文件和状态。用户锁定及版本冲突会阻止写入。
- 自由 JS 的动态场景对象、动态拼接触发点、无法隔离的共享绘图引用可能无法安全重写。不要用全文替换绕过错误；改成显式引用后重试。录音文件按场景命名的旧工程暂不支持界面场景改名，先迁移录音并验证。
- Agent 直接写文件后运行 `node ".dsh/skills/explainroo/scripts/validate.mjs" "<项目目录>"`，也可用 `explainroo_validate({id})`。验证没有 TTS，不执行项目代码，失败退出码为 1。检查场景函数匹配、同场触发点重名、画面与手动覆盖中的触发点，以及封面场景。
- 静态检查不证明所有自定义 JS 运行行为或画面布局正确。还需查看实际无声预览；不为验证调用会隐式补配音的旧 CLI check。

原版引擎保持未修改。插件在临时兼容副本中把中文场景、标记和封面转换为确定性的 ASCII 名称，只重写静态确认的引用。工作台、手动覆盖和原始项目仍使用中文 ID；有效配音元数据在读写时映射，原文件不会被批量英文化。动态引用无法安全确认时明确失败，不以全文替换猜测。
