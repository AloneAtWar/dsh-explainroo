# 架构

本工程是独立的 DSH Desktop 插件。内置 explainroo 副本由本仓库维护，不修改其他仓库或外部安装的引擎。

```text
DSH 原生对话                     原生工作台 / 开发 UI
   │ explainroo_* 工具                 │ Typert / 开发 HTTP
   └──────────── Workbench 服务 ────────┘
                         │
              Projects / Previews / Tasks
                         │
              视频项目 + 内置 explainroo 引擎
```

## Host 与数据真源

`src/index.ts` 注册 Cordis 插件；`ExplainrooService` 通过 Typert 暴露服务，界面和工具共用具名请求及严格 codec。DSH 库为 peer，避免重复宿主注册表和任务调度器。

`script.md`、`scenes.js`、`video.json` 是项目真源。手动覆盖与锁定在 `.explainroo/studio.json`，撤销历史保留最多 30 步。保存需匹配 revision，计算包含讲稿、配置、可达 JS 模块及覆盖状态。同项目写入串行化；锁定不可由 AI 解开，冲突保留界面草稿。

跨文件改动通过私有事务日志提交，异常时回滚；读取前恢复中断事务。撤销核对被改文件的期望内容，外部再次编辑后拒绝覆盖。配音设置独立保存，旁白撤销不会回滚已选音色。

## 工作台与初始化

工作台目录兼容根项目、直属子项目和 `projects/<目录名>/`。创建项目使用排他目录和文件创建，拒绝路径穿越或链接容器；识别文件最后写入。失败只回收本次创建且未被外部改动的文件。

新建工作区安装包内完整 skill，按二进制复制字体等资源，生成仅含本机路径的 `engine.json`。已有自定义 skill 不覆盖。运行时另注册 `explainroo-workbench` 指引；插件关闭后工作区文件仍可使用。

零场景项目返回空时间线与起始画布，不调用强制需要场景的渲染入口。新增分镜后沿用轮询进入完整编辑器。

## 旁白与中文名称

旁白由一个 ProseMirror 文档维护：正文、换行以及不可拆分的触发点和停顿节点。所有文本事务补回被删除的原标签并排除重复、外来节点，因此整段替换不会丢失触发点。序列化还原原始 token。

标签使用 pointer capture 拖动，`posAtCoords / coordsAtPos` 定位并绘制插入线，松开后提交同一节点的移动事务。取消、失去捕获或销毁时清理。正文与位置共享本地撤销重做；中文组合输入由编辑器处理。切换分镜说明不卸载草稿，保存或还原时才重置。

场景、触发点和封面直接接受合法的 NFC 中文名称，没有别名或翻译表。改名使用 Acorn 定位静态引用，一次修改讲稿、画面模块、封面和手动时序。共享或动态引用无法安全改写时拒绝提交。有效合成配音仅更新对应元数据或复制同字节 WAV，不重新生成语音。

右键复制只输出 JSON，包含项目、场景、对象或触发点身份、复制时 revision 和锁定。触发点包含后续文字、正文偏移及未保存状态。复制不发送消息，后续修改仍需读取最新 revision。

## 预览、导出与配音

预览沿用引擎的画布、字体、绘图 API 和时间线。`scene-adapter.ts` 在基础对象绘制前叠加手动属性；覆盖记录对象 id、kind 和 baseText，防止 AI 重排后应用到不匹配的对象。自定义绘图没有通用拖拽。

全片主题、背景、纹理和字幕保存在 `studio.appearance`，由同一适配器应用于预览和导出。导出在 `.explainroo/runs/<taskId>/` 中物化独立快照，复制 JS 子模块、素材和有效配音，调用引擎与 FFmpeg。

无配音或缓存失效时，预览使用预计时间，不下载语音模型或调用 TTS。`render` 按需补配音，`sheet` 使用无声时间线生成 JPG；显式 `voice / check` 工具保留。任务同项目互斥，取消只终止本服务拥有的进程树。生成的配音仅在原 revision 未变时回写，避免覆盖外部修改。

导出前运行无声静态引用验证，不执行项目 JavaScript。动态定义无法确认时明确失败；静态验证不替代实际画面验收。

进度来自阶段、配音场数和帧数，无计时器伪造进度。下载使用绑定已完成任务、限时有效的随机能力 URL，检查合法输出路径；Desktop 的附件下载进入系统保存框。

## DSH 原生集成

Client 为单文件 ModuleLoader 包，React 由宿主提供。只注册 `embedded` 业务面板，默认原生会话在左、业务面板在右；不重建聊天框、不声明 `customFrame`、不自动发送消息。

`native-split.ts` 在面板内提供可聚焦分隔手柄，保存比例，支持拖动、方向键、双击和 Enter 恢复。适配已验证的 Desktop DOM；结构变化或上下布局时回退，不影响对话节点。卸载清理监听与布局覆盖。

`project-session.ts` 校验会话归属，优先复用当前会话；取消或切换后不迟到创建会话。未保存编辑阻止项目恢复覆盖。

`scene-references.ts` 注册原生 `@` 来源，在发送时读取最新场景、备注、覆盖与锁定。引用以右侧明确选择的项目为准，可与会话目录不同；异步读取前后核对会话和项目身份。

## 本地服务与生命周期

开发 Vite API、画布代理和下载服务只监听本机，检查 Host / Origin；开发 API 使用随机令牌。iframe 消息核对来源窗口、channel 和 origin，文件服务沿用引擎白名单。

每次插件注册均为 effect；卸载注销面板、工具与引用来源，并关闭预览和所属进程。机器路径、凭据、模型缓存、开发副本和导出媒体不进入发布包。

## 边界

复杂画面仍由代码维护；尚未提供结构化新建场景、任意动画反编译、素材管理或专业多轨剪辑。录音按场景迁移和录音缓存识别不完整。扩展这些能力时应保留文件真源、锁定、revision 与局部覆盖边界。
