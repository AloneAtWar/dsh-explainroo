# 设计与交互

工作台面向在 DSH 中与 AI 协作制作讲解视频的创作者。主要流程是选择项目、预览分镜、调整内容、导出。

## 布局与主题

左侧保留 DSH 原生对话，右侧业务面板由场景列表、真实画布和对象属性组成。原生分隔手柄可调整宽度；窄屏将属性区放到下方。

默认亮色，顶部一键切换暗色并记住偏好。界面模式与视频主题分离，切换界面不会改变导出。沿用琥珀色主动作、青紫色时间线及现有轻淡入反馈。

## 项目与设置

顶部项目面板提供搜索、当前项目、路径和新建入口。工作台根目录在设置中维护，一个工作台可管理多个视频项目。

设置采用限高弹窗，工作台与配音两个标签，共用固定保存与取消栏。配音服务和音色优先展示，模型、语气及服务地址折叠在高级设置。

空工作台显示选择目录或新建入口；零场景显示当前视频背景的起始画布与原生创作入口。初始化只准备本地文件，不生成示例场景或调用语音服务。

## 画面与旁白

画布顶部维护主题、背景色、纹理和字幕。改名与复制定位统一走右键菜单；画布工具栏不放重命名或锁定按钮，锁定状态由 DSH 侧维护并在界面以图标与提示呈现。

画布下方同屏展示本场旁白与分镜说明，不再切换标签：旁白占据主要编辑区，分镜说明固定为底部紧凑输入区。分镜说明是不会朗读的构图、对象关系与动画顺序备注，通过标签悬停解释。

旁白是连续富文本，触发点和停顿穿插在正文中。标签带拖动手柄和插入线，能移动但不能被退格、删除或整段替换误删。正文支持中文输入、多行粘贴和展开编辑；Ctrl+Z / Ctrl+Y 同时处理文字与位置。右键提供改名和纯 JSON 定位复制，改名前先保存当前草稿。

时间轴只显示真实画面标记、播放与时间定位，不重复旁白正文，不绘制虚构音频波形。

## 属性与修改保护

基础文字、方框、圆、图标和图片可选择、拖动或在属性中调整。复杂自定义绘图继续交给代码。保存与还原有明确入口，场景锁定阻止编辑。

场景、画面、对象和触发点的右键菜单沿用同一种定位交接方式。复制只有 JSON，不增加自然语言教程，不自动发送对话。成功使用短提示，错误可关闭，提示不挤占编辑区域。

## 导出

顶栏提供视频与分镜图导出。任务后台执行，状态位显示百分比和取消，完成后进入系统保存流程，可再次保存。视频内部补齐配音；界面没有独立任务记录页、生成配音或检查画面按钮。

## 验收状态

关注无项目、零场景、读取中、预计时长、有效配音、未保存、锁定、保存冲突、导出进度、失败及取消。保留原生对话、草稿和布局，避免切换标签或刷新导致内容丢失。
